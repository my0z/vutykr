# 쿠팡 파트너스 멀티 사이트

Worker 하나가 여러 도메인을 받아 사이트별 설정 파일대로 보여 줍니다.

## 구조
- `sites/<이름>.js` 사이트 하나의 모든 설정 (이름 색상 분야 검색어 문구)
- `sites/index.js` 사이트 목록
- `src/` 모든 사이트가 함께 쓰는 코드
- `wrangler.toml` 도메인과 저장소 연결

## 새 도메인 추가
```bash
node scripts/new-site.mjs 영문이름 도메인.kr "사이트 이름"
```
1. 만들어진 `sites/영문이름.js`의 문구와 분야와 검색어를 고친다
2. 브랜치에 푸시하면 임시 주소에 배포된다 (`?site=영문이름`으로 확인)
3. main에 합친 뒤 도메인을 Cloudflare에 연결하고 `wrangler.toml`의 routes에 추가한다
4. `CRON_SITES`에 이름을 더하면 상품 자동 갱신이 시작된다

## 공통 규칙
- 쿠팡 API 키는 한 쌍을 모든 사이트가 공유하고 호출은 한 시간에 사이트 하나씩 돌아가며 한다
- 사이트마다 KV와 D1이 따로 있어 데이터가 섞이지 않는다
- 관리자 화면은 각 도메인의 `/0`
